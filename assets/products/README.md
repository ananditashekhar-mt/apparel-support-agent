# Demo catalogue photography

These are AI-generated sample images for Threadly's fictional catalogue, not photographs of actual vendor inventory. Images were created with the built-in image generation tool, not downloaded from Google or Pinterest.

The application maps photographs by Product_Name, Colour, and product Gender. Customer gender is never used to select the image: gift purchases retain the ordered product's photograph.

`image-manifest.json` records the final filenames, variant identities, and generation prompts. Original full-resolution images remain in the generation output folder; selected project assets are copied here. No customer information is sent in image prompts.
